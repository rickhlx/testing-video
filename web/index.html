Video test matrix

Twelve ways of putting the same 1080p24 clip on screen, each isolating a different layer. Every page reports the same telemetry, so two pages can be compared directly. Run them in order: the first page that misbehaves names the layer at fault.

Reading the picture. The clip carries a burned-in indicator so drops are visible, not just counted. White marker steps one slot per frame and wraps once a second. Smooth sweep is healthy; a skipped slot is a dropped frame. Green blocks are the frame number in binary, most significant bit on the left — readable from a photo of a misbehaving client. Red box blinks twice a second as a peripheral cadence check.
